PixInsight Update Assistant

This address is an update repository for PixInsight. It is meant for PixInsight, not for a web browser.

To install the add-on, open Resources > Updates > Manage Repositories in PixInsight and add this address, with the slash at the end:

https://gm-polyakov.github.io/pixinsight-update/

What the add-on does, and the rest of the steps: github.com/GM-Polyakov/pixinsight-update

PixInsight Update Assistant is a free, independent add-on. It is not made or endorsed by Pleiades Astrophoto.
